# 🎮 WebGame #18 – Shape Creator

---

## 🇬🇧 English

Simple creative browser app built with **HTML, CSS and JavaScript**.

### 🎮 About the game
Create colorful shapes by clicking on the canvas.

- Choose a shape (circle, square, triangle, star)  
- Choose a color 🎨  
- Click anywhere on the canvas to create shapes  
- Use delete mode to remove shapes 🗑️  
- Build your own mini artwork or pattern  

### 🚀 How to run
1. Download or clone the repository  
2. Open the file:  
   shape-creator.html  
3. Use directly in your browser  

### 🛠 Technologies
- HTML  
- CSS  
- JavaScript (Vanilla)  

### 📌 Features
- Multiple shape types  
- Multiple colors  
- Interactive canvas  
- Delete mode  
- Shape counter  
- Clear canvas functionality  
- Simple and clean UI
