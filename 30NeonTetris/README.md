# 🧱 Neon Tetris

A modern neon-inspired Tetris game built with pure HTML, CSS and JavaScript.

Stack glowing blocks, clear lines, build combos and climb through increasingly challenging levels. Featuring a cyberpunk-inspired visual style, smooth gameplay and modern quality-of-life features such as Hold Piece, Ghost Piece and Hard Drop.

---

# 🎮 Features

- Modern neon visual style
- Responsive design
- Multiple levels
- Score system
- Combo system
- High score saving
- Hold Piece
- Next Piece preview
- Ghost Piece
- Hard Drop
- Soft Drop
- Pause system
- Particle effects
- Screen shake effects
- Line clear animations
- Mobile controls
- Local storage support

---

# 🕹️ Gameplay

The goal is simple:

- Place falling tetrominoes
- Complete horizontal lines
- Prevent blocks from reaching the top
- Build combos for higher scores
- Reach higher levels

As levels increase, blocks fall faster and the challenge becomes greater.

---

# ✨ Modern Features

## 👻 Ghost Piece

Displays where the current piece will land.

Benefits:

- Better planning
- Faster gameplay
- More precise placement

---

## 📦 Hold Piece

Store one tetromino for later use.

Benefits:

- Save important pieces
- Improve strategy
- Create Tetris setups

Controls:

```text
C
```

---

## ⚡ Hard Drop

Instantly drops the current piece to the bottom.

Controls:

```text
SPACE
```

Benefits:

- Faster gameplay
- Additional score rewards

---

## 🔥 Combo System

Clear lines consecutively to build combos.

Example:

```text
Combo x1
Combo x2
Combo x3
Combo x4
```

Higher combos provide bonus points.
