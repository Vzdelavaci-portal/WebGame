# 🎮 WebGame #16 – Tower Balance

---

## 🇬🇧 English

Simple browser game built with **HTML, CSS and JavaScript**.

### 🎮 About the game
Stack blocks as precisely as possible to build the tallest tower.

- A moving block slides left and right  
- Click (or press Space) to drop it  
- Align it with the previous block  
- Misalignment reduces the block size  
- Miss completely = game over 😅  

### 🚀 How to run
1. Download or clone the repository  
2. Open the file:  
   tower-balance.html  
3. Play directly in your browser  

### 🛠 Technologies
- HTML  
- CSS  
- JavaScript (Vanilla)  

### 📌 Features
- Moving block mechanic  
- Precision-based gameplay  
- Increasing difficulty (speed)  
- Score tracking  
- Progressive shrinking blocks  
- Click + keyboard controls  
- Restart functionality  
- Simple and clean UI

## 🇨🇿 Česky

Jednoduchá webová hra vytvořená pomocí **HTML, CSS a JavaScriptu**.

### 🎮 O hře
Skládej bloky co nejpřesněji a postav co nejvyšší věž.

- Blok se pohybuje ze strany na stranu  
- Klikni (nebo stiskni mezerník) pro jeho spuštění  
- Snaž se ho zarovnat s předchozím blokem  
- Nepřesnost zmenší velikost bloku  
- Pokud mineš úplně = konec hry 😅
