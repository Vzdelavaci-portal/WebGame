# 🎮 WebGame #22 – Find the Pattern

---

## 🇬🇧 English

Simple browser brain game built with **HTML, CSS and JavaScript**.

### 🎮 About the game
Find the missing number in the sequence before choosing the correct answer.

- Analyze the number pattern 🧠  
- Choose the correct missing value  
- Wrong answers cost lives 😅  
- Patterns become more challenging over time  
- Test your logic and focus  

### 🚀 How to run
1. Download or clone the repository  
2. Open the file:  
   find-the-pattern.html  
3. Play directly in your browser  

### 🛠 Technologies
- HTML  
- CSS  
- JavaScript (Vanilla)  

### 📌 Features
- Random number patterns  
- Multiple choice answers  
- Score system  
- Lives system  
- Dynamic question generation  
- Restart functionality  
- Simple and clean UI
