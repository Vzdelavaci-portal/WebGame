# 🐍 Neon Snake

A modern web version of the classic Snake game built entirely with HTML, CSS and JavaScript.

This is not just a simple snake made of squares — the game includes a modern neon design, animated food, particle effects, obstacles, levels and responsive controls.

---

# 🎮 Demo

Simply open:

```text
index.html
```

- modern neon visual style

- obstacles

1. Download or copy the `index.html` file

3. Click **Start Game**

---

# 🧠 How It Works

The game uses HTML5 Canvas. The snake moves across a grid, collects food and grows over time.

As the score increases:

- the game speed increases
- new obstacles appear
- the level goes up

Collision happens when the snake hits:

- the wall
- its own body
- an obstacle

The best score is automatically saved using `localStorage`.
