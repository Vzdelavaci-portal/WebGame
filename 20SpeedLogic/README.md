# 🎮 WebGame #20 – Speed Logic

---

## 🇬🇧 English

Simple browser brain game built with **HTML, CSS and JavaScript**.

### 🎮 About the game
Answer logic and math questions as fast as possible before time runs out.

- Decide if the statement is TRUE or FALSE  
- Solve quick math and logic challenges 🧠  
- The game gets faster every round ⚡  
- Wrong answers or slow reactions cost lives 😅  
- Try to survive as long as possible  

### 🚀 How to run
1. Download or clone the repository  
2. Open the file:  
   speed-logic.html  
3. Play directly in your browser  

### 🛠 Technologies
- HTML  
- CSS  
- JavaScript (Vanilla)  

### 📌 Features
- Random math and logic questions  
- TRUE / FALSE gameplay  
- Timer system  
- Increasing difficulty  
- Score tracking  
- Lives system  
- Visual countdown bar  
- Restart functionality  
- Simple and clean UI
