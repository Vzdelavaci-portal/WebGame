# 🎮 WebGame #23 – Split Focus

---

## 🇬🇧 English

Simple browser reaction game built with **HTML, CSS and JavaScript**.

### 🎮 About the game
Test your focus by managing two areas at the same time.

- Targets appear on both sides of the screen 🔵🔴  
- Click them before they disappear  
- The game becomes faster over time ⚡  
- Missing targets costs lives 😅  
- Try to survive as long as possible  

### 🚀 How to run
1. Download or clone the repository  
2. Open the file:  
   split-focus.html  
3. Play directly in your browser  

### 🛠 Technologies
- HTML  
- CSS  
- JavaScript (Vanilla)  

### 📌 Features
- Dual-area gameplay  
- Random target spawning  
- Increasing difficulty  
- Score system  
- Lives system  
- Level progression  
- Fast reaction gameplay  
- Restart functionality  
- Simple and clean UI
