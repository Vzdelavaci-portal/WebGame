# 🧱 Neon Brick Breaker

A modern neon-style Arkanoid / Breakout inspired browser game built with pure HTML, CSS and JavaScript.

Destroy glowing bricks, collect bonuses, unlock new levels and use passwords to continue your progress later.

The project focuses on modern visuals, arcade gameplay and clean structure without using any external libraries or frameworks.

---

# 🎮 Features

- modern neon cyberpunk visual style
- HTML5 Canvas rendering
- smooth arcade gameplay
- 10 different levels
- unique brick layouts
- level password system
- particle explosion effects
- animated star background
- responsive controls
- desktop and mobile support
- score system
- best score saving using localStorage
- pause system
- bonuses / power-ups
- increasing difficulty
- smooth paddle and ball physics
- multi-ball system
- Game Over and Win screens

---

# 🔐 Level Password System

Every level has its own password.

After completing a level, the game displays a password for the next one.

Example:

```text
Level Complete!
Password for next level: CYBER4
```

You can later enter the password from the main menu and continue from that level.

# ⚡ Bonuses / Power-Ups

Bricks can randomly drop bonuses.

## Included bonuses

| Bonus | Effect |
|---|---|
| Wide Paddle | Makes paddle larger |
| Extra Life | Adds one life |
| Multi Ball | Creates additional balls |
