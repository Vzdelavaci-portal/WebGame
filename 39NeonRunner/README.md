# 🏃 Neon Runner

**Neon Runner** is a fast-paced endless runner set in a futuristic neon cyber world.

Run as far as possible, jump over obstacles, collect neon coins and try to beat your high score. ⚡

---

## 🎮 How to Play

The character runs automatically.

Your goal is simple:

> **Run → Jump → Avoid → Collect → Survive**

### Controls

| Action | Control |
|---|---|
| Jump | `SPACE` |
| Jump | `↑ Arrow` |
| Double Jump | Press jump twice |
| Mobile Jump | `JUMP` button |
| Pause | `P` / `ESC` |
| Restart | `Restart` button |

## 🚧 Obstacles

There are several different obstacle types:

- 🟥 Neon Box
- 🔴 Laser Block
- 🟣 Tall Barrier

The game becomes progressively faster, making the obstacles harder to avoid.
