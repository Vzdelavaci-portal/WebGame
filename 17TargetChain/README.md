# 🎮 WebGame #17 – Target Chain

---

## 🇬🇧 English

Simple browser game built with **HTML, CSS and JavaScript**.

### 🎮 About the game
Click targets as fast as possible and build the highest combo chain.

- Targets appear randomly on the screen  
- Click them before they disappear 🎯  
- Every successful hit increases your combo 🔥  
- Higher combo = more points  
- Missing targets resets your combo and costs lives 😅  

### 🚀 How to run
1. Download or clone the repository  
2. Open the file:  
   target-chain.html  
3. Play directly in your browser  

### 🛠 Technologies
- HTML  
- CSS  
- JavaScript (Vanilla)  

### 📌 Features
- Random target spawning  
- Combo system 🔥  
- Increasing difficulty (faster spawning)  
- Score tracking  
- Lives system  
- Animated targets  
- Restart functionality  
- Simple and clean UI

## 🇨🇿 Česky

Jednoduchá webová hra vytvořená pomocí **HTML, CSS a JavaScriptu**.

### 🎮 O hře
Klikni na targety co nejrychleji a vytvoř co největší combo sérii.

- Targety se náhodně objevují na obrazovce  
- Klikni na ně dříve, než zmizí 🎯  
- Každý úspěšný zásah zvyšuje combo 🔥  
- Vyšší combo = více bodů  
- Minutý target resetuje combo a ubere život 😅  

### 🚀 Jak spustit
1. Stáhni nebo naklonuj repozitář  
2. Otevři soubor:  
   target-chain.html  
3. Hraj přímo v prohlížeči
