# 🚀 Neon Space Defender

A modern neon-style Space Invaders inspired game built with pure HTML, CSS and JavaScript.

Destroy enemy waves, collect boosters, survive longer and achieve the highest score possible.

The game is fully playable directly in the browser and built inside a single HTML file.

---

# 🎮 Features

- modern neon sci-fi visual style
- built with HTML5 Canvas
- animated star background
- custom spaceship graphics
- enemy waves
- enemy shooting system
- particle explosion effects
- level progression
- increasing difficulty
- score and high score system
- responsive controls
- desktop and mobile support
- localStorage high score saving
- boosters / power-ups system
- pause system
- Game Over screen

---

# ⚡ Boosters / Power-Ups

Enemies can randomly drop boosters.

## Available boosters

| Booster | Effect |
|---|---|
| Double Shot | Fires two bullets at once |
| Rapid Fire | Faster shooting speed |
| Shield | Blocks one enemy hit |
| Extra Life | Adds one extra life |

Boosters are intentionally balanced:

- Double Shot → common
- Rapid Fire → common
- Shield → less common
- Extra Life → rare

# 🚀 How To Run

1. Download or copy the `index.html` file
2. Open it in your browser
3. Click **Start Game**
4. Play

No installation required.

No frameworks required.

No server required.

---

# 🧠 Gameplay

You control a spaceship at the bottom of the screen.

Your objective:

- destroy enemies
- avoid enemy bullets
- collect boosters
- survive as long as possible

As the level increases:

- enemies move faster
- enemies shoot more often
- difficulty increases

The game ends when:

- you lose all lives
- enemies reach your position
