# 🏎️ Neon Racer

A modern neon-style endless racing game built with pure HTML, CSS and JavaScript.

Drive through futuristic neon roads, avoid traffic, collect coins and use nitro boosts to survive as long as possible.

The game is inspired by classic arcade racers combined with modern cyberpunk visuals and smooth HTML5 Canvas gameplay.

- score system

- animated road

- mobile controls
- pause system

- futuristic UI

---

# 🚗 Gameplay

The goal is simple:

- avoid crashing into traffic
- survive as long as possible
- collect coins
- use nitro wisely
- beat your best score

As the game progresses:

- traffic becomes faster
- spawn rate increases
- the game becomes more chaotic

---

# ⚡ Nitro System

The player can activate nitro for temporary speed boost.

## Nitro Features

- increases movement speed
- creates neon boost flames
- slowly drains while active
- regenerates over time
- can be recharged by collecting coins

---

# 🪙 Coins

Coins randomly spawn on the road.

Collecting coins gives:

- extra score
- nitro refill
- particle effects

---

# 💥 Collision System

When the player crashes into another vehicle:

- one life is lost
- explosion particles appear
- temporary invincibility activates

The game ends after losing all lives.

---

# 🕹️ Controls

## Desktop

| Action | Keys |
|---|---|
| Move Left | `A` / `Arrow Left` |
| Move Right | `D` / `Arrow Right` |
| Nitro | `Space` |
| Pause | `P` |

---

## Mobile

Touch controls automatically appear on smaller screens.

- Left button → move left
- Right button → move right
- Lightning button → nitro
