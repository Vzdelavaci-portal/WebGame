# 🎮 WebGame #15 – Color Swap Trap

---

## 🇬🇧 English

Simple browser game built with **HTML, CSS and JavaScript**.

### 🎮 About the game
Click the correct color before the cards swap and time runs out.

- A target color is displayed  
- Cards constantly change positions  
- Click the correct color before time runs out ⏱️  
- Wrong choice or slow reaction = lose a life 😅  
- The game gets faster over time ⚡  

### 🚀 How to run
1. Download or clone the repository  
2. Open the file:  
   color-swap-trap.html  
3. Play directly in your browser  

### 🛠 Technologies
- HTML  
- CSS  
- JavaScript (Vanilla)  

### 📌 Features
- Dynamic color swapping  
- Increasing difficulty (faster rounds)  
- Timer system  
- Score tracking  
- Lives system  
- Instant feedback  
- Restart functionality  
- Simple and clean UI
