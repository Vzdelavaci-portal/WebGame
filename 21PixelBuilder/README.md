# 🎮 WebGame #21 – Pixel Builder

---

## 🇬🇧 English

Simple creative browser app built with **HTML, CSS and JavaScript**.

### 🎮 About the game
Create your own pixel art using colors and a drawing grid.

- Choose different colors 🎨  
- Draw by clicking or dragging on the grid  
- Use the eraser tool 🧽  
- Clear the entire canvas anytime  
- Build your own pixel creations and patterns ✨  

### 🚀 How to run
1. Download or clone the repository  
2. Open the file:  
   pixel-builder.html  
3. Use directly in your browser  

### 🛠 Technologies
- HTML  
- CSS  
- JavaScript (Vanilla)  

### 📌 Features
- 16×16 pixel drawing grid  
- Multiple color choices  
- Drag-to-draw support  
- Eraser tool  
- Pixel counter  
- Clear canvas functionality  
- Responsive layout  
- Simple and clean UI
