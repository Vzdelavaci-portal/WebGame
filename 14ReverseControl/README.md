# 🎮 WebGame #14 – Reverse Control

---

## 🇬🇧 English

Simple browser game built with **HTML, CSS and JavaScript**.

### 🎮 About the game
Reach the goal, but be careful — the controls are reversed!

- Use arrow keys or buttons to move  
- Controls work in the **opposite direction**  
- Avoid obstacles ❌  
- Reach the green goal to win 🎯  

### 🚀 How to run
1. Download or clone the repository  
2. Open the file:  
   reverse-control.html  
3. Play directly in your browser  

### 🛠 Technologies
- HTML  
- CSS  
- JavaScript (Vanilla)  

### 📌 Features
- Reversed controls mechanic  
- Collision detection (obstacles)  
- Win condition (goal)  
- Keyboard + button controls  
- Restart functionality  
- Simple and clean UI
