# 🎮 WebGame #19 – Merge Numbers

---

## 🇬🇧 English

Simple browser puzzle game built with **HTML, CSS and JavaScript**.

### 🎮 About the game
Merge matching numbers to create bigger values and reach the highest score possible.

- Use arrow keys to move tiles  
- Merge matching numbers together  
- Each merge creates a bigger number 🔢  
- The board slowly fills up  
- Try to reach 2048 and beyond 🚀  

### 🚀 How to run
1. Download or clone the repository  
2. Open the file:  
   merge-numbers.html  
3. Play directly in your browser  

### 🛠 Technologies
- HTML  
- CSS  
- JavaScript (Vanilla)  

### 📌 Features
- 2048-style gameplay  
- Keyboard controls  
- Score system  
- Best score saving (localStorage)  
- Dynamic tile merging  
- Game over detection  
- Restart functionality  
- Simple and clean UI
