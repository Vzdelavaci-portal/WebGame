# 🎮 WebGame #24 – Path Builder

---

## 🇬🇧 English

Simple browser puzzle game built with **HTML, CSS and JavaScript**.

### 🎮 About the game
Build a connected path from the green start to the red goal.

- Create a continuous path tile by tile 🟦  
- Avoid black obstacle blocks ⬛  
- You have a limited number of moves ⚡  
- Use Undo to fix mistakes  
- Each level becomes more difficult  

### 🚀 How to run
1. Download or clone the repository  
2. Open the file:  
   path-builder.html  
3. Play directly in your browser  

### 🛠 Technologies
- HTML  
- CSS  
- JavaScript (Vanilla)  

### 📌 Features
- Grid-based puzzle gameplay  
- Connected path building  
- Random obstacle generation  
- Limited move system  
- Undo functionality  
- Progressive difficulty  
- Level system  
- Responsive layout  
- Simple and clean UI
